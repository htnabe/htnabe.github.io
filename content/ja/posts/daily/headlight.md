今回購入したのはGENTOS LEDヘッドライト（MAX 300ルーメン）です。公式サイトは[こちら](https://www.gentos.jp/products/series/auva/va-05d)。

最近、早朝・夜間にランニング etc.をしようと思っても足元がおぼつかないせいでとても怖かったので購入しました。

購入してから2週間、使用回数は5回だけですが、今のところかなり良い買い物だったなぁと感じたのでレビューしておきます。

## 主な仕様

- 光源：白色LEDと暖色LED各1個
- 本体質量（約）：81g（電池含む）
- 電池：単4電池2本
- 可動域：80°
- 防水：1m防水仕様（IP66、IP67準拠）
- 最長照射距離：66m
- 明るさと点灯時間
  {{<table "table">}}
  |                |             |             |            |                   |
  | -------------- | ----------- | ----------- | ---------- | :---------------: |
  | 明るさ（約）   | 300ルーメン | 100ルーメン | 30ルーメン | 6ルーメン（暖色） |
  | 点灯時間（約） | 3.5時間     | 10時間      | 30時間     |      74時間       |
  {{</table>}}

とまぁ、重要なスペックは上記の通りです。ちなみに防水性能についてはIP67で1m防水とのことなので1mの深さに30分間水没させても浸水しないことを意味しています[^1]。しかしながら実際の明るさや照射範囲、そして実際の付け心地とかベルトの長さが今一分からないですよね…

ということで詳しい仕様について説明します。

### 実際の明るさと照射範囲

まず300ルーメンから。

{{<cldimg url="https://res.cloudinary.com/takenoko/image/upload/v1670677728/daily/head-light/300lumen_ivuwnm.webp" alt="picture_of_300lumen">}}

300ルーメンだとかなり明るく、大体2車線分くらいの幅を10m先くらいまで照らしてくれます。街灯の無い道でもかなり安心して歩ける明るさです。

次に100ルーメン。

{{<cldimg url="https://res.cloudinary.com/takenoko/image/upload/v1670677929/daily/head-light/100lumen_jidgp1.webp" alt="picture_of_100lumen">}}

300ルーメンの場合と比べると暗く感じるものの、街灯のある道だと特に問題なさそうな明るさです。照射範囲は大体1車線分くらいで、5m程度先まで照らしてくれています。

次は30ルーメン。

{{<cldimg url="https://res.cloudinary.com/takenoko/image/upload/v1670678113/daily/head-light/30lumen_mxycz0.webp" alt="picture_of_30lumen">}}

さすがにこのくらいになると足元だけしか照らせません。日の入り・日の出前後の時間帯など、ある程度明るい場面で使ったり、「ここに歩行者がいますよ～」っていうアピールに使うのが正解っぽいですね。

最後に6ルーメンはもはやまともに写真を取れる明るさではなかったので省略します。多少手元を照らすのに使える程度の明るさです。

### 付け心地

5回ほどランニングしてみたのですが、ベルトの内側に滑り止めがあるため、汗でずれ落ちるようなことはありませんでした。

{{<cldimg url="https://res.cloudinary.com/takenoko/image/upload/v1670759347/daily/head-light/headlight_anti_slip_doqvqy.webp" alt="picture_of_belt">}}

またベルトの長さを自由に変えられるので、頭等にフィットする長さにしていればずれ落ちることはほとんど無いと思います。

### ベルトの長さ

結構長めですが腰回りに付けるのは無理そうです。実際の測定結果は周囲約62cmでした。

{{<cldimg url="https://res.cloudinary.com/takenoko/image/upload/v1670759001/daily/head-light/headlight_length1_tp9nh7.webp" alt="length_of_belt1">}}

片側だけで31cmくらいなので周囲62cmくらいですね。

{{<cldimg url="https://res.cloudinary.com/takenoko/image/upload/v1670759001/daily/head-light/headlight_length2_u7rfxm.webp" alt="length_of_belt2">}}

### 電池の持ちについて

私は一回のランニングで平均1時間程度しか走らないので3回に1度の頻度で電池を充電しています。そのおかげで今のところランニング中の電池切れは体験していません。ただ点灯時間がめちゃくちゃ長い訳ではないので、充電し忘れたりするとちょっと怖いですね…笑

## 総評

大体3000円くらい（2022/12月現在）で買えるヘッドライトとしてはかなりスペック高い上に使い勝手も良いです。あとは耐久性が気になりますね。半年後か来年くらいにまたレビューしようかな。
